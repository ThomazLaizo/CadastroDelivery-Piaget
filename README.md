Aplicação web simples para cadastrar aplicativos de delivery (nome e país de origem) e exibi-los em uma tabela. Construída com HTML, CSS e JavaScript puro, sem frameworks ou dependências.

## ✨ Funcionalidades

- Cadastro de aplicativos com **nome** e **país**
- Listagem dinâmica em tabela, atualizada a cada novo cadastro
- Validação: alerta quando algum campo é enviado em branco
- Tema claro/escuro automático, conforme a preferência do sistema

> ⚠️ Os dados ficam apenas em memória: ao recarregar a página, a lista volta ao estado inicial (apenas o iFood).

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (manipulação do DOM e eventos)

## 🚀 Como executar

Não há dependências nem etapa de build.

```bash
# clone o repositório
git clone https://github.com/ThomazLaizo/Incurcoes-Piaget.git
cd Incurcoes-Piaget
```

Depois, abra o arquivo `index.html` no navegador.
